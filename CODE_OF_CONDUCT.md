# Code of conduct

## The short version

Be decent to people. Assume good faith. Argue about the code, not the person writing it.

## What is expected

Treat other contributors with respect, including when you think they are wrong. Accept that people have different levels of experience, different hardware, different hearing, and different reasons for being here. Give feedback on the work rather than on the person. When you are given feedback, read it before replying.

## What is not acceptable

Harassment of any kind. Insults, personal attacks, and sustained hostility. Sexual language or imagery. Publishing anyone's private information without permission. Demeaning comments about someone's identity, background, or ability.

The same standard applies in issues, pull requests, commit messages, and anywhere else this project is discussed.

## Enforcement

Maintainers may edit or remove comments, commits, issues, and pull requests that break these rules, and may block repeat offenders. Report a problem by opening an issue, or by contacting a maintainer directly if the report should not be public. Reports will be handled discreetly.

## Scope

This applies in project spaces and when someone is representing the project elsewhere.
